# mod-forge SQL

Applied by hand (the module's tables aren't in the core's DB updater). Table names are unchanged from the
core patch era (`item_affix*`, `item_unique*`, `item_generated*`), so databases that ran core patch
`0001-item-affixes` need nothing: these are the same files the core's updater applied from `data/sql/custom`.

- Fresh databases: `characters/` into `acore_characters`, then `world/` into `acore_world`, each in file order.
- `world/2026_10_13_01_item_affix_data.sql` and `world/2026_10_13_02_item_affix_pool.sql` are generated by
  wowproject's `tools/item-affixes/gen.py` (see its docstring). Re-run them after regenerating; the pool file must come from the
  same `pools.tsv` as the client's `patch-enUS-4.MPQ`.
